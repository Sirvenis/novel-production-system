# Stage-to-Defect-Type Mapping

This mapping makes defect escape rate measurable.

| Stage | Defect types primarily responsible for catching |
|---|---|
| Authority/source lock | stale path, wrong branch, untracked canonical prose, source conflict, missing status/handoff, policy conflict |
| Integrity verification | missing/duplicate chapters, truncation, repeated paragraphs, bad encoding, broken headings, abnormal chapter lengths |
| Context loading | missing canon/voice/series context, stale project records, insufficient read depth, irrelevant context bloat |
| Developmental diagnosis | broken premise promise, weak motivation, pacing collapse, missing escalation, structural redundancy, underdeveloped relationship/character arcs |
| Research/fact verification | false/unsupported real-world claims, procedural impossibility, cultural/historical misuse, over-certainty where fiction should be labelled invented |
| Continuity/canon audit | internal contradictions, timeline errors, object/location drift, prior-book canon conflicts, unresolved setup/payoff mismatch |
| Controlled editorial intervention | scope creep, overrewrite, failure to address approved finding, introduced prose/canon damage |
| Mechanical QA | typo/format/chapter numbering/repetition/export defects, markdown/front matter issues |
| Fresh-reader evaluation | confusion, boredom, emotional disengagement, unsatisfying pressure/release, reader-contract mismatch |
| Revision verification | target defect not fixed, new regression introduced, unapproved change slipped in |
| Regression checking | known historical defect missed, false positive pattern, genre/series voice misread, repeated pipeline blind spot |
| Final quality gate | unresolved critical/major defects, insufficient evidence, handoff/provenance gaps |
