# Proposed Execution Sequence

## Phase 0 — Review of this design

Andrew / Arden inspect this frozen architecture. No manuscript or Writer candidate is processed.

## Phase 1 — Writer qualification design approval only

If approved later, run Packet 01 for GPT-5.5, Kimi K2.6, and GLM-5.2 under exact route/zero-tool controls. Only survivors advance to Packet 02 holdout. This is separate from real-manuscript pipeline testing.

## Phase 2 — Acceptance pilot A: Night Shift recovery test

Run diagnosis-only preflight, integrity, context, developmental diagnosis, research trigger analysis, continuity audit, and proposed intervention plan. Stop before prose changes unless Andrew / Arden approve the plan.

## Phase 3 — Acceptance pilot B: Anunnaki Book 4 restraint test

Run source lock, integrity, targeted diagnosis, canon/context, research trigger analysis, continuity audit, and preservation-risk review. Stop before prose changes unless Andrew / Arden approve targeted revisions.

## Phase 4 — Retrospective regression diagnosis on 16 Library-ready novels

Run read-only diagnosis/audit samples or staged whole-manuscript audits as approved. No revision. Record known-defect rediscovery, credible new findings, false positives, overediting proposals, and genre consistency.

## Phase 5 — Pipeline synthesis

Compare pipeline behavior across raw-draft recovery, strong-draft preservation, and ready-novel regression. Revise the pipeline architecture before any institutional rollout.

## Phase 6 — Full-book creation pipeline trial

Only after Writer qualification and post-draft pipeline acceptance are sufficient, run an approved new book from concept/architecture through Writer and post-draft production.
