# Anunnaki Book 4 Acceptance-Test Plan

Purpose: PRESERVATION / RESTRAINT TEST.

Question: Can the production pipeline improve an already-strong manuscript while resisting unnecessary rewriting, homogenisation, voice damage, canon drift, and editorial overreach?

Known historical status: complete first draft; 87,006 words; 25 chapters; strong GPT-5.5 production provenance; existing review indicates strong draft requiring targeted revision rather than wholesale reconstruction.

## Initial allowed mode

Diagnosis/audit only. No prose change until Andrew / Arden approve targeted revisions. Because Anunnaki canon/prose is GPT-5.5-sensitive, any future canon/prose judgement must verify runtime/model according to the Anunnaki repo policy.

## Test stages

1. Source lock: verify canonical Anunnaki repo, Book 4 manuscript path, branch/remote, current status/handoff, file hashes, model policy.
2. Integrity: word/chapter count, chapter sequence, duplicate/missing sections, repeated paragraphs, export readiness.
3. Context: Book 4 architecture/status, series bible, prior-books summaries, canon files, existing review findings.
4. Developmental diagnosis: only material issues; separate genuine defects from taste/preference.
5. Preservation/anti-overediting review: identify voice, pace, mythic escalation, character relationships, and action-adventure qualities to protect.
6. Conditional research trigger: historical/archaeological/cultural verification only where reader-trust depends on real-world claims; do not punish intentional mythic invention.
7. Continuity/canon audit: contradictions against Books 1–3 and Book 4 internal rules.
8. Targeted revision proposal: no wholesale reconstruction unless evidence contradicts the historical review.
9. Stop gate: Andrew / Arden inspect findings before edits.

## Acceptance evidence sought

- Does the pipeline show restraint on a strong draft?
- Does it resist generic polishing that damages Anunnaki's action/adventure voice?
- Does it preserve GPT-5.5 provenance boundaries?
- Does it correctly use research without turning mythic fiction into a textbook?
- Does it produce a smaller, evidence-backed revision plan?


## Fresh source-lock before intervention

If Andrew / Arden later approve prose-changing intervention, the manuscript must be source-locked again immediately before edits: branch, remote parity, dirty state, source file hashes, word/chapter counts, and approved scope.
