# Night Shift Book 1 Acceptance-Test Plan

Purpose: DEVELOPMENT / RECOVERY TEST.

Question: Can the production pipeline take a comparatively raw complete first draft, identify genuine weaknesses, preserve strengths, improve systematically, and move it toward publication quality without unnecessary rewriting or canon drift?

Known historical status: complete first draft; 45,555 words; 16 chapters; originally generated by GLM-5.2; substantial raw Writer evidence; lacks complete production-pipeline survival evidence.

## Initial allowed mode

Design-approved future run should begin diagnosis/audit only. No prose change until Andrew / Arden approve a revision plan.

## Test stages

1. Source lock: verify canonical nurse-fiction repo/path, manuscript file(s), branch/remote, status/handoff, source hashes.
2. Integrity: word/chapter counts, chapter-length distribution, duplicate/missing headings, truncation, repeated paragraphs.
3. Context: load nurse-fiction SOUL/status/series plan/voice guardrails if present; identify missing guardrails as a pipeline finding, not a reason to invent canon.
4. Developmental diagnosis: evaluate premise, protagonist pressure, chapter function, escalation, character integration, ending promise, and reader contract.
5. Research trigger: medical/nursing/procedural verification likely required. Build a claim register before research; do not let research rewrite the story.
6. Continuity/canon audit: internal contradictions, timing, character roles, hospital/ward logic, recurring facts.
7. Preservation review: identify strengths that must not be flattened during recovery.
8. Controlled intervention plan: classify proposed fixes as none/surgical/chapter-level/structural; estimate revision burden.
9. Stop gate: Andrew / Arden review before any prose modifications.

## Acceptance evidence sought

- Does the pipeline distinguish raw-draft weakness from model prejudice against GLM?
- Does it preserve useful ambiguity, nursing atmosphere, and existing horror/escalation strengths?
- Does it avoid wholesale rewrite as default?
- Does research improve credibility without procedural overloading?
- Does it produce a clear, bounded revision plan Andrew can approve or reject?


## Fresh source-lock before intervention

If Andrew / Arden later approve prose-changing intervention, the manuscript must be source-locked again immediately before edits: branch, remote parity, dirty state, source file hashes, word/chapter counts, and approved scope.
