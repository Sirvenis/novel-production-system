# Writer Validator

`validate_writer_submission.py` checks deterministic gates that can be machine-tested before blind human scoring:

- minimum prose word count;
- required marker presence, uniqueness, and order;
- hard literal-detail retention;
- forbidden premature-resolution phrases.

It cannot score prose quality, voice, emotional control, summary substitution, or canon nuance. Those remain blind-reader/editor/showrunner responsibilities.
