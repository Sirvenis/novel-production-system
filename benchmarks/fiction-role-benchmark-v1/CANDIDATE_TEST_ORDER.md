# Candidate Test Order — Approval Preview

No runs are authorised by this document. It sequences candidates to settle cheap questions before expensive ones.

## Wave 0 — Calibration

- Deterministic validators against included positive/negative tests.
- One already-included Codex comparison route only if ordinary account allowance permits and Andrew starts the run phase.
- Purpose: calibrate prompts, output budgets, scoring spread, and blinding—not select winners.

## Wave 1 — Low/medium usage role screens

- Writer/reader: Gemma 4 31B, MiniMax M2.7, Mistral Large 3, GPT-5.6 Luna comparison.
- Research/continuity: Qwen 3.5 397B, DeepSeek V4 Flash, Mistral Large 3.
- Mechanical-QA: GPT-OSS 20B, Nemotron 3 Nano 30B, plus deterministic-only baseline.
- Showrunner/editor: GLM 5.2, Qwen 3.5 397B, Mistral Large 3, GPT-5.6 Terra comparison.

## Wave 2 — Proven and high-usage comparators

- Kimi K2.6 on writer, reader, and autonomous-role cells where prior Arden evidence makes it a meaningful baseline.
- Nemotron 3 Ultra and GPT-5.6 Sol only on roles where Wave 1 leaves material uncertainty.
- DeepSeek V4 Pro only for developmental/continuity cells not settled by Flash or GLM 5.2.

## Wave 3 — Extra-credit gate

- Kimi K3 only after Andrew explicitly approves extra-credit use and only on the unresolved highest-value role cells.

Within each wave, run deterministic/mechanical roles first, then researcher/continuity, then reader/editor/showrunner, and writer last after score calibration. Randomise candidate order inside each role and lock blind scores before reveal.
